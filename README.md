# CMF 标注工具

把渲染图变成一张可以直接交付的 **CMF 标注总表**：在图上拉引线标注部件、填写材质与工艺参数、套上项目信息栏，一键导出 PNG / PDF / 分层 SVG。

纯前端实现，所有计算都在浏览器里完成，**图片不会上传到任何服务器**。

## 使用

**方式一：下载后用**（断网也能用）

1. 打开 [`cmf-annotator.html`](cmf-annotator.html)，点右上角 **Download raw file** 下载（或右键「链接另存为」）
2. 双击，用 Chrome / Edge 打开
3. 把渲染图拖进窗口（或 `Ctrl/⌘ + V` 直接粘贴截图）就能开始标

整个工具就装在这一个文件里——不装 Node、不联网、没有外链资源。发给同事、拷进内网盘，都是这一个文件。

**方式二：在线打开**：<https://cmf.ceetang.com>  
想先看它能做什么、适合谁用：<https://cmf.ceetang.com/about.html>

## 三步上手

1. **放图**：拖入渲染图，左侧「素材」可以继续加图
2. **标**：工具条选「标注」，在图上拖出引线，右栏按 CMF 五栏填部件 / 材质 / 工艺 / 颜色 / 备注
3. **出图**：左下「导出设置」选画板与分辨率，导出 PNG / PDF / 分层 SVG

## 关于存档

工程存在**你自己的浏览器**里，不上传服务器。换浏览器、换电脑、清理浏览器数据后旧存档看不到——重要项目请用「导出项目文件」备份成一个 JSON。
