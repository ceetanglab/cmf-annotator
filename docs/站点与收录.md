# 站点与收录

这份文档只讲「网站这一层」：`about.html` / 404 / 图标 / 分享图 / robots / sitemap / 缓存与压缩。
工具本身怎么用见 [`使用说明.md`](使用说明.md)，服务器与 COS 的部署细节见 [`../deploy/cos.md`](../deploy/cos.md)。

---

## 一、文件放在哪

站点附属文件全部在 **`site/`**，构建时原样拷到上线目录，不和 `src`（应用代码）、`assets`（品牌母版）混在一起。

| 文件 | 作用 | 改它的场景 |
|---|---|---|
| `about.html` | 工具介绍页，获客与 SEO 落地页 | 改文案、加截图、补 FAQ |
| `404.html` | 错误页（COS 静态网站的错误文档） | 一般不用动 |
| `og-cover.png` | 1200×630 分享图 | 换品牌图时替换 |
| `favicon.ico` | 浏览器标签页 / 收藏夹（16+32） | 换 logo 时由脚本重生成 |
| `favicon-32.png` | 现代浏览器备用 | 同上 |
| `apple-touch-icon.png` | iOS 添加到主屏幕（180） | 同上 |
| `icon.svg` | 矢量图标，优先加载 | 同上 |
| `robots.txt` | 抓取规则 + sitemap 地址 | 基本不动 |
| `sitemap.xml` | 收录清单（首页 + about） | 新增页面时补一条 |

图标母版只有一套：`assets/icons/*.png` 和 `assets/icon.svg`。
`site/` 里的四个图标是派生物，由 `npm run icons` 生成，**不要手改**。

```bash
npm run icons   # 从 assets/icons 重新生成 favicon.ico 等四个文件
```

## 二、三个页面

| URL | 内容 | 收录 |
|---|---|---|
| `/` | 工具本体（单文件内联 JS/CSS） | 主入口 |
| `/about.html` | 介绍页：痛点、三步上手、能力、FAQ | 主要落地页 |
| `/404.html` | 错误页，`noindex` | 不收录 |

`404.html` 在 COS 里设为**错误文档**。之前错误文档填的是 `index.html`，任何不存在的路径都会回退整页 697KB，favicon、robots 一旦 404 就白传一整页，已改掉。

## 三、分享卡片

首页和 about 都写了 OG / Twitter 标签，图片指向：

```text
https://cmf.ceetang.com/og-cover.png
```

三个注意点：

1. **必须是外链绝对地址**。抓取器不会读 data URI，也不能是相对路径。
2. **微信不吃标准 OG**。微信只取页面 title、description 和首图；朋友圈那种自定义标题 + 大图卡片需要 JS-SDK + 公众号 + 域名授权，个人主体做不了。Telegram、飞书、钉钉、Slack 才是完整大图卡片。
3. 图片的 `Content-Type` 要是 `image/png`，COS 一般按扩展名自动识别，传完核对一次即可。

## 四、收录

### robots.txt

```text
User-agent: *
Allow: /

Sitemap: https://cmf.ceetang.com/sitemap.xml
```

### sitemap.xml

两条 URL：首页、`about.html`。新增页面时补一条，并把 `lastmod` 改成当天。

### 提交入口

| 平台 | 地址 | 操作 |
|---|---|---|
| 百度 | <https://ziyuan.baidu.com> | 普通收录 → sitemap → 填 `https://cmf.ceetang.com/sitemap.xml` |
| Google | <https://search.google.com/search-console> | 索引 → 站点地图 → 填 `sitemap.xml` |

百度注意：

- 每日提交配额按站点权重给，新站常见「上限 0 / 余额 0」，按钮是灰的。填了主体备案号、站点验证通过后会逐步放开。
- 配额每天刷新、不可累计。
- 配额为 0 时，靠外链让蜘蛛自己发现，或在「快速抓取」里单独提交。
- 收录周期 2 周到 2 个月都算正常，纯工具站更慢。

Google 没有这种配额，通常几天到两周。

### 自查

```text
site:cmf.ceetang.com
```

有结果即已收录。也可以用蜘蛛 UA 直接验证能不能抓：

```bash
curl -A "Mozilla/5.0 (compatible; Baiduspider/2.0; +http://www.baidu.com/search/spider.html)" \
  -s -o /dev/null -w "%{http_code}\n" https://cmf.ceetang.com/
```

## 五、缓存与压缩

### 缓存

三个 HTML 在 COS 对象上的元数据：

```text
Cache-Control: public, max-age=300
```

- 5 分钟内复用缓存，超过后回源。
- 不要设 `no-cache`。腾讯云 CDN 是「写缓存时压缩」，`no-cache` 不落缓存，压缩会被一起跳过。
- 图片、图标可以设 7 天。

### 压缩

腾讯云 CDN → 高级配置 → 智能压缩：

- 类型：**全部文件**（不要用「文件后缀」，`/` 没有后缀会漏掉首页）
- 范围：`256 Byte ~ 2 MB`
- 方式：Gzip + Brotli

首页压缩前后：699,959 → 223,397 字节（Brotli，降 68%）。

验证：

```bash
curl -s -o /dev/null -D - -H "Accept-Encoding: gzip, br" https://cmf.ceetang.com/ \
  | grep -i "content-encoding\|content-length\|age"
```

要看到 `Content-Encoding: br` 或 `gzip`。

> 测试时不要带随机查询参数，CDN 缓存键包含查询串，带 `?t=123` 会永远 Cache Miss。
> 本机有代理时加 `--noproxy "*"`，否则拿到的可能是代理处理过的响应。

### 发版后

改了 HTML 要刷新 CDN：

```text
https://cmf.ceetang.com/
https://cmf.ceetang.com/about.html
```

不刷也可以，最多等 5 分钟自然过期。浏览器自己还有一层缓存，验证时用 `Ctrl + F5`。

## 六、发版检查清单

```bash
npm run build:single
coscmd upload -r dist/site/ /
```

1. `dist/site/` 里是 **10 个文件**，不是只有 `index.html`
2. COS 里 `index.html` 的 `Content-Type` 是 `text/html; charset=utf-8`
3. 三个 HTML 的 `Cache-Control` 是 `public, max-age=300`
4. 静态网站错误文档是 `404.html`
5. 刷新 `/` 和 `/about.html`
6. 新增页面时更新 `sitemap.xml` 的 `lastmod`，并回站长平台重新提交
