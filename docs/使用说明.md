# CMF 标注工具 · 使用说明

> 把渲染图变成一张可直接交付的 CMF 标注总表。  
> 全程在浏览器本地运行，图片不上传服务器。

在线使用：<https://cmf.ceetang.com>
离线使用：下载 [`cmf-annotator.html`](../cmf-annotator.html)，双击即用

> **离线版**：仓库里那份 `cmf-annotator.html` 就是整个工具——HTML、JS、CSS、图标、二维码全在一个文件里，没有外链、不用装 Node、不用联网。点开文件页面右上角的 **Download raw file**（或右键「链接另存为」）存到本地，**双击用 Chrome / Edge 打开**即可，功能和在线版完全一样。想发给同事、带进没网的评审室、塞进内网盘，都拷这一个文件就行。

---

## 一、它解决什么问题

设计评审时最费时间的往往不是渲染，而是「这张图哪个件是什么材质、什么工艺、什么颜色」说不清楚。口头讲一遍、微信打一段字、再用 PPT 圈一圈，信息散在不同地方，最后谁也说不准。

这个工具把这件事收进一张图：**在渲染图上拉引线，标注框里按 CMF 五栏填参数，右侧项目信息栏交代背景，导出一张完整的总表**。图上每个部件的材质工艺都写在旁边，评审时不用再解释第二遍。

## 二、界面布局

界面分三块，各管一件事：

```
┌─────────────────────────────────────────────┐
│  顶部：撤销 / 工具 / 形状 / 视图               │
├──────────┬──────────────────┬───────────────┤
│  左侧     │                  │   右侧         │
│  项目     │      画布        │  全局 / 标注    │
│  素材     │   （无限画布）    │  / 画板 设置    │
│  图层     │                  │               │
│  画板     │                  │               │
├──────────┴──────────────────┴───────────────┤
│  左下：导出设置 / 快捷键 / 关于                │
└─────────────────────────────────────────────┘
```

一句话记法：**左边放东西，中间干活，右边调参数。**

## 三、顶部工具条

从左到右四组，只管「画什么」和「怎么看」：

1. **撤销 / 重做**：所有操作都可回溯，误删标注按 `Ctrl+Z` 即可
2. **选择 / 标注**：两个核心工具
   - 选择：点选、拖动、拖角缩放已有对象
   - 标注：双击画布生成一条带材料 / 工艺栏目的 CMF 引线标注
3. **文本 / 直线 / 多段线 / 圆形 / 矩形**：五种形状标注工具，建完立刻选中并自动跳到右侧「标注」页（形状属性就在那一页里），`Esc` 回到选择工具
   - **文本**：在画布空白处**双击**就落一个默认大小的文本框
   - **直线 / 圆形 / 矩形**：都是**两点定大小**——在起点**双击**，移动鼠标会跟出一条**实线预览**（就是成品的样子），到需要的位置**再双击**就是终点；起点到终点的对角线决定长短 / 大小
   - 画直线 / 圆形 / 矩形时按住 **Shift**：直线锁成水平或垂直（按拖得更长的那个方向），圆形锁成正圆，矩形锁成正方形
   - **多段线是逐点画的**：单击落一个点，点数不限，双击收尾；收尾后再单击就是新的一条，`Esc` 丢掉没画完的半截
4. **适应 / 100%**：视图控制。适应＝整张图连同画板铺满窗口；100%＝图比窗口小就按原像素显示（1 像素对 1 像素），图比窗口大就缩到刚好铺满一屏——渲染图动辄三四千像素，真按屏幕像素铺出去只看得到一个角落，所以这里封了顶，要看细节请用滚轮或底部缩放条放大

导入与导出的出入口统一收在左栏：**最上面的「项目」**管工程的增加 / 打开 / 导入（见第四节）；**左下「导出设置」**默认收起，点标题即可展开，里面是导出项目文件、导出选中画板、导出所有画板。工具条不再重复放这些按钮，给形状工具腾位置。

### 形状标注

五种形状都是真正可编辑的对象，和渲染图、CMF 标注共用一套图层顺序：

| 工具 | 怎么画 | 可以在右侧「标注」页改什么 |
| --- | --- | --- |
| 文本 | 双击空白处，落一个默认「文字」的文本框 | 文字内容、字号、文字颜色、透明度 |
| 直线 | 双击起点 → 移动 → 双击终点；`Shift` 锁水平 / 垂直 | 颜色、线宽、透明度 |
| 多段线 | 单击逐点落、双击收尾，点多少段由你定 | 颜色、线宽、透明度 |
| 圆形 | 双击起点 → 双击终点（对角线就是外框）；`Shift` 锁正圆 | 颜色、线宽、填充、透明度 |
| 矩形 | 双击起点 → 双击终点（对角线就是外框）；`Shift` 锁正方形 | 颜色、线宽、填充、透明度 |

- **文字统一用思源黑体**（没装时自动回退到苹方 / 微软雅黑），不提供字体下拉，避免同事打开时字体缺失。
- **没在画的时候，形状工具也是「选择工具」**：单击已有形状就能选中、拖动、拖手柄改尺寸，不用先切回「选择」；只有落完起点、正在拉预览的那一下才由绘制接管。多段线也一样——落第一个点之前，点在形状上就是选中它。
- 绘制时的预览**就是成品的模样**：实线、和成品同色同粗细，直线 / 多段线都不再用虚线示意。
- 画到一半想反悔：`Esc`（或 `Ctrl/⌘ + 左键`）回到选择工具，半截的起点会被丢掉，不会留在画布上。
- 拖动形状可移动；选中后**四角和四边中都有手柄**，拖哪边改哪边——矩形能拖成长条、圆形能拖成椭圆，默认**不锁长宽比例**。
- 右栏「尺寸」栏可以精确到像素：直接填**宽 / 高**；点锁形按钮切「锁定比例」（拖角恢复等比、改宽时高度自动跟着算），点双箭头按钮**互换长宽**。文本框的长宽跟内容走，不出这一栏。
- 多段线整体跟着包围盒变形，不需要逐点拖。
- `Shift` 点选多个形状后，右栏的每一项改动都会**批量生效**。
- 双击形状会选中它并把光标送到文字输入框（文本框才有）。
- 形状会一起进图层列表（行首带「形」标记）、一起参与对齐 / 分组 / 复制 / 撤销，也一起出图（SVG 里是独立可编辑的矢量元素）。

## 四、左侧：项目、素材与标注管理

### 1. 项目

左栏最上面一块是「项目」。**一个窗口 = 一份工程**，靠地址栏里的 `?doc=xxxx` 区分——所以同时开几个窗口，各干各的活，不会互相覆盖。

- **当前**：本窗口这份工程的名字，取自项目信息栏的「项目」栏。改项目名这里跟着变，浏览器标签页标题也跟着变——多开时靠标题认窗口。新窗口的默认名按「未命名项目-01 / -02 / -03…」两位补零自动排下去，不会几个窗口重名
- **增加项目**：**新建一份空白工程**并在新窗口打开，当前窗口一动不动。新窗口从 0 开始，拖图进来才落库，不会在「最近工程」里留下空条目。要把已有的 JSON 变成新工程，请用「导入项目」在当前窗口打开
- **导入项目**：选一个 JSON **覆盖当前窗口**。会先确认一次——覆盖不可撤销，想留底先「导出设置 → 导出项目文件」
- **最近工程**：这台电脑浏览器里存着的所有工程，按修改时间倒序。点条目＝在新窗口打开；行尾悬停出两个动作：
  - **本窗口**：在当前窗口切过去。切之前会先把眼下的改动存好
  - **垃圾桶**：从本地删掉这份存档（导出过的 JSON 文件不受影响）。当前这份不给删，免得边看边删

工程之间不共享任何东西：素材、图层、画板、信息栏、水印各归各的。

想开一份空工程？新开一个标签页访问 <https://cmf.ceetang.com> 就是新的空工程；网址上带 `?doc=` 的则是那份工程本身。

### 2. 素材

点虚线上传区或直接拖图进画布，可一次选多张，按顺序并排拼接。

**建议用 PNG。** 渲染图带透明通道或大面积渐变时，PNG 不会有 JPEG 的块状压缩伪影；标注线压在浅色背景上也更干净。同尺寸的多张图并排后是同一张长图，导出不会变形。

除了拖文件，还可以**直接 `Ctrl / ⌘ + V` 粘贴剪贴板里的图片**（截图、从别的文档里复制的图都行），图会落在当前视口中心。

素材缩略图右上角悬停出现删除按钮，删图不会连带删除该图上的标注。按住 `Shift` 点缩略图可以多选，和画布上的多选是同一套选中。

### 3. 图层

图层区把**渲染图、CMF 标注和形状标注放在同一张列表里**（形状行行首带「形」标记），自上而下就是「谁压在谁上面」。每行可以：

- 点行选中（画布上同步高亮，`Shift` 点行可多选）
- 点眼睛图标临时隐藏，做对比图或排查错位时有用
- 点垃圾桶删除；删掉图片行，素材区里那张图同时消失
- 行尾的色点是这条标注的当前颜色（图片行没有色点）

**改层级**：直接把行拖到目标行上，落在上半部＝插到它上面，下半部＝插到它下面。拖的是一行就动一行，拖的是分组就整组一起动。

**分组**：选中两个以上图层，点「分组」（或按 `Ctrl / ⌘ + G`），它们就归到一个可折叠的分组里。分组的好处是：

- 一眼看清「这几张图 + 这几条标注」是一伙的
- 点分组头＝选中整组，可以一起对齐、一起删
- 分组的眼睛管全组显隐，不用逐行点
- 把某一行拖到分组头上，它会直接进这个组
- 双击分组名可改名，「解散」把成员放回列表、对象仍留在画布上

标注多到十几条时，图层就是你的索引表——**比在画布上找引线快得多**。

### 4. 画板

画板**不是内容，是取景框**：它决定"哪一块画面被导出、导多大、用什么底色"。同一张画布上可以摆很多块画板，各自框不同的局部，各自出一张图——整体效果图配细节图、正面配侧面，都在一个工程里做完。

关键区别记一句：**移动图片不会带着画板跑**。画板钉在自己框住的那块地方，图片挪走了，框还在原处。

每行画板显示：序号、名称、比例 · 尺寸 · 底色。行尾两个小按钮：

- **定位**（方框图标）：视图跳到这块画板并居中显示
- **垃圾桶**：删掉这块画板。**画布上的图片和标注不受影响**，只是不再有这块取景框

**新建与编辑**：

- 「新建画板」按当前内容的大小框出一块（默认 A4 横向比例），**排在现有画板右侧的空白处**，不会和已有的重叠，视图自动跳过去。因为它不在内容上，新画板的「自动画布」默认是关的——想让它跟着内容长，在右侧打开开关，或点「贴合内容」
- 「贴合内容」把边框收拢到**正好包住这块画板里的内容**（图片、标注、形状）；板外的素材不算在内
- 画布上直接**拖动**画板移动位置，拖四角**缩放**尺寸；只有**边框**能点中，画板中间是空的，点/拖会落到下面的图片或画布上
- **双击画板名**可改名。名字会进文件名——多块一起导出时是 `项目名-细节图.png` 这样
- 点画布空白处取消画板选择（多选时一起取消），缩放框同时收起
- 至少保留一块，删光了工具就没有导出范围了

**画板比例**在右侧「画板」页设置：A4 / A3 / 方形 / 16:9 / 自由等。改比例会以中心为锚点缩放边框，**只放大不裁切**，保证框里的内容不被切掉。

拖角点改大小时，有具体规格（A4、1:1、16:9…）的画板**保持等比**，免得拖出一个「A4 但没那么 A4」的怪比例；选「自由」就放开限制，宽高各自拉，随便什么形状都行。

选到**「自由」**时，比例按钮下面会多出一行**宽 × 高**的数值框：直接填像素精调，不用靠拖角点凑数。改宽度只动宽、高度不变，**边框中心保持不动**；点行尾的双箭头按钮**互换长宽**（竖图横过来、横图竖过去），中心同样不动。这里填的就是画布像素，96 DPI 导出时 1:1 —— 想让细节图更清晰，把数值调大就行。有具体规格的比例不出这一行，因为长短边由纸张比例定死了。

**底色**默认透明。透明底导出 PNG / WebP / SVG 时保留透明通道，拿去排版软件里直接叠在版面上；JPEG 和 PDF 没有透明通道，会强制填白。需要白底、浅灰底或深色底时在这里点色板。

**自动画布**开关：打开后画板**只向外扩，不会往里缩**。画板里的渲染图变大（或往板里再放一张图），边框自动长到能装下它；把图删掉或移回来，边框停在原处不动——这样可以避免「框会自己跑」的错觉。要精确收回来，点「贴合内容」。

**多块画板时只跟渲染图**：每块画板只按落在它里面的**图片素材**贴合，标注框、形状、项目信息栏这些伸到板外的元素不算数。所以两块画板同时打开自动画布，也不会互相把对方的内容吞进来、越贴越大最后叠在一起——两块并排的细节图各框各的图，边框永远不会重叠。一块画板都不沾的图（比如放在板外远处的）也不会把任何画板撑大。只有板里**一张图都没有**时（纯标注板），才退回按全部内容算。

> 一件素材同时被两块画板框住时（比如一块大板套着一块小板），它会归给**框得更严实**的那块——重叠比例更高，比例打平时给面积更小的一块。所以如果你发现某块画板之前被内容撑得很大，选中它点一次「贴合内容」就会收回自己那份。

> 只算图也有代价：标注框或信息栏如果伸到画板外面，导出时会被裁掉。需要它们进图的话，把标注拖回板内，或者关掉自动画布手动拖一下边框。

**多块画板一起改**：在左栏列表里按住 `Shift` 点多行，或在画布上 `Shift` 点画板边框多选。这时右侧「画板」页改比例、改底色会对所有选中的画板生效，删除按钮变成「删除选中的 N 块」。多选后**拖任意一块的边框**是整组平移，**拖角点**是整组等比缩放——各块的相对位置和大小一起变，拿来把一套图统一放大 20% 正好。

## 五、画布：无限工作区

画布没有边界，图不会"出画"：

- **滚轮**：以光标为中心缩放
- **空白处拖动**：平移
- **双击空白**：在「标注」工具下生成一条 CMF 引线标注；在「文本」工具下落一个文本框；在「直线 / 圆形 / 矩形」下**定起点**（到终点再双击一次）
- **中键拖动**：任何模式下都能平移
- **`Ctrl / ⌘ + V`**：剪贴板里是图片就贴到画布上，是复制过的图层就粘贴图层

缩放不影响导出结果。导出的尺寸只由**画板的边框大小、画板比例和分辨率**决定，与当前视图缩放到多少无关。

## 六、右侧：全局 / 标注 / 画板设置

右栏有「全局」「标注」「画板」三页，**切换是自动的，不需要手动点**：

- 在画布上**点中某条 CMF 标注** → 自动跳到「标注」页，编辑这条标注的颜色、材质、工艺、引线样式
- 在画布上**点中某个形状** → 同样跳到「标注」页，页里换成形状的表单（颜色 / 粗细 / 透明度 / 填充 / 文字）——标注和形状共用一个设置框，右下角不会多出一页页签
- 在画布上**点中某块画板**（或点左栏画板列表的某行）→ 自动跳到「画板」页，调比例、底色、自动画布
- 在画布上**点空白处**（或选中图片、信息栏）→ 自动跳回「全局」页

这个设计的意思是：你点哪儿，右边就显示哪儿能改的东西。

### 标注页：每条标注可以有自己的颜色

「标注」页除了填写颜色 / 材质 / 工艺这些内容，下半部分是这个标注自己的**引线与锚点样式**：端点样式、粗细、大小，以及**引线颜色**。

引线颜色默认「跟随全局」——全局换色它跟着变。点一下色板里的任一颜色（或用取色器选），这条标注就**单独锁一个颜色**，之后全局怎么换都不会覆盖它；点「恢复跟随全局」即可解锁。

适合的场景：主体标注统一用红，需要特别说明的工艺用黑色或深灰标出来，一眼就能区分。

### 材质 / 工艺：点标签，不用手打

「材质」「工艺」两栏下面各有一个「常用材质 / 常用工艺」按钮，展开是一排标签：

- 点一下加进去，再点一下去掉；多选用「 + 」连接，如 `磨砂 + 拉丝`
- 清单是 CMF 常见项：材质 30 项（ABS / PC / PC+ABS / 铝合金 / 不锈钢 / 硅胶 …），工艺 23 项（哑面 / 磨砂 / 电镀 / 阳极氧化 / 丝印 …），各带一个「其他」
- 标签只是快捷输入，填完仍是一行文字，可以接着手改；手打顿号也会被认出来（`哑面、亮面、本色` 这三项会同时点亮）
- 项目信息栏里的「材质」「工艺」两栏也有同样的按钮，改的是**整份工程**的总材质 / 总工艺，与单个部件的填写互不影响

### 颜色：框里存的是潘通色号

「颜色」栏以**色号**为准，输入框里写的就是色号（如 `186 C`）：

- **框里带 Pantone 前缀**：显示成 `Pantone 186 C`；手打 `186 C`、`186C`、`pantone 186 c`、`Cool Gray 11 C` 都认，确认后统一规范成这个写法
- **改色号 = 换颜色**：色号一改（边打边生效，不用等回车），左边的色块立刻变成这个色号的近似屏色，不用再自己对着色卡挑
- **想对着屏幕上的颜色来**：点左边的色块取色，或把 `#C8102E` 这样的色值填进框里，回车 / 失焦后自动换成最接近的色号
- **输入框下面的 ΔE**：只有「手选过颜色、和色号不完全一致」时才出现，告诉你两者差多少。ΔE 小于 2 基本看不出差别，2～5 很接近，再大只能算同一色系
- 认不出的写法（如 `99999 C`）原样留着，不猜，也不给一个假色号

老工程里存的是色值，打开时会自动换成最接近的色号，原色值仍留在色块上（所以 ΔE 还能告诉你差多少）。

> 内置的是 Pantone Solid Coated（C 卡）1831 色的**屏幕近似值**，用来在屏幕上把说法对齐；正式打样、下单请拿色卡实物对色。

### 形状的「标注设置」（就在「标注」页里）

选中一个或多个形状，右栏「标注」页就会换成形状表单——不单独开页签，避免右栏顶部被页签挤满。项都是即时生效的，多选时整批一起改：

- **文字内容 / 字号**（仅文本框）：文字自动换行，文本框高度跟着内容重排
- **颜色**：色板 + 取色器，文本框改的是字色，其余改的是描边色
- **线条粗细**（文本框没有）
- **填充**（仅矩形 / 圆形）：可选颜色，也可点「无填充」只留描边
- **透明度**：10%～100%
- **操作**：复制副本、删除

### 全局页包含五块

**① 对齐**  
多选后使用：左对齐、水平居中、右对齐、顶部对齐、垂直居中、底部对齐、等距分布。调整多条标注的视觉秩序时用，比手动拖准。

**② 项目信息栏**  
图右侧那一栏的编辑器。可改栏目名与内容（公司 / 部门 / 项目 / 设计师 / 版本号 / 时间 / 颜色 / 材质 / 工艺 / 制作工序 / 特别说明），可增删栏目、拖动调序、切换标题横线、上传品牌 logo。

其中两个栏目是**自动维护**的，不用手填：

- **时间**：每次打开工程自动刷新为当天日期
- **版本号**：每次导出成功后自动 +0.1（V1.0 → V1.1 → … → V1.9 → V2.0）。同一版连点几次导出（先出 PNG 再出 PDF）只算一次，不会一次跳两档

如果把它们改名成别的名字，就变成普通栏目，不再自动更新。

**③ 全局引线样式**  
线宽、颜色、箭头大小、锚点半径。改动会同步到已有全部标注，之后新增的标注也沿用这套默认值。

**④ 水印**  
单点或平铺两种模式，尺寸、透明度、密度可调。

**⑤ 模板**  
把当前这套设置（引线样式 + 栏目结构）存成模板，下次换项目一键套用，不用重新配。模板可重命名、可导出 `.json` 发给同事导入。

## 七、导出

导出这件事分两层：**画板决定框哪儿**（左栏画板列表 + 右侧「画板」页），**导出设置决定出多大、出什么格式**（左下「导出设置」）。比例和底色归画板，分辨率和格式归导出设置，各管一段，不重复。

左下「导出设置」里的参数：

1. **当前画板**：这块面板改的是哪块画板。选中多块时显示「N 块」，改分辨率会对所有选中项生效
2. **文件名**：默认跟项目名一致（左栏「项目」里的名字），扩展名按格式自动补。导出多块画板时后面会缀上画板名
3. **分辨率**：96 / 150 / 300 DPI，或「自定义」填任意值，或勾「导出画板原分辨率」——不缩放，直接按画板当前像素 1:1 出图
4. **格式**：PNG / JPEG / WebP / PDF / SVG

这些设置**跟着画板走**，不是全局的。正面图要 300 DPI 的 PNG、细节图要原分辨率的 JPEG，各设各的，互不影响。

### 两种导出方式

**导出选中画板**（左下「导出设置」底部按钮）：导出当前选中的那块，多选就出多张。日常改一版看一张，用这个。

**导出所有画板**（导出设置底部）：一次把全部画板出完，一次性下载。「所有画板用当前选中的画板设置」**默认不勾**，即各画板按自己的分辨率与格式出图——想做「整图 150 DPI + 细节图 300 DPI」这种混搭就保持不勾。要让全部画板统一成一套规格（一套交付物通常要一致），把它勾上，下面那行小字会写明参考哪一块、出成什么（如「参考『画板 1』：150 DPI · PNG」）；多块画板都选着时，参考的是**你先点的那块**。

这个勾选是**导出时覆盖**：本次全部按参考画板的规格出图，但各画板自己存的设置不会被改动（小字里的「仅本次生效」就是这个意思）。要真的改掉，选中画板后在上面的分辨率 / 格式里改。

多块画板导出会排队下（每张隔两百多毫秒），这是浏览器的下载节流限制，不是卡住了。文件多时留意浏览器的「允许多个文件下载」提示。

### 关于 SVG

需要交付给下游继续编辑、或要拿去排版时选 SVG。它和位图不同：

- 渲染图、每条 CMF 标注、形状标注、项目信息栏、水印各自是独立图层
- 文字是真正的文本，不是图形
- 在 Illustrator 里可以逐层单独选中拖动、直接改字

画板底色为透明时，SVG 里是一个空的「纸面」图层，不会硬塞一块白色矩形。

PDF 是单页位图，不能分层（浏览器端无法子集化中文字体）。需要分层可编辑时用 SVG，在 AI 里另存 PDF 即可。

## 八、存档与数据安全

**所有数据只在你自己的浏览器里。**

图片、CMF 标注、形状标注、设置都存在本机浏览器的 IndexedDB 里，**按工程分槽**（每个窗口一个槽位），不上传任何服务器。改动随手自动保存：刷新、收藏网址、关掉页面再打开，都会回到同一份工程。

代价是：**换电脑、换浏览器、清理浏览器数据后，旧存档看不到。**

离线版（本地那个 `cmf-annotator.html`）也一样：存档跟着打开它的浏览器走，并且和网页版的存档**互不相通**——浏览器按来源分开存，`file://` 和 `https://` 是两套。想在两边接着做，用「导出项目文件」搬一次即可。

因此重要项目请用「导出项目文件」备份成一个文件，需要时用左栏「项目 → 导入项目」整块恢复——图片、CMF 标注、形状标注、信息栏、水印、画板与导出设置全都在里面，导入后可以继续修改，不是只读快照。

**一次做几个方案时**用「增加项目」各开一个窗口：每份工程一个窗口，互不干扰。唯一要避开的是**同一份工程开两个窗口同时改**——最后保存的那个会盖掉另一个。

建议节奏：**阶段性导出项目文件，跟成品图一起归档。**

## 十、常见问题

**导出的图边缘发糊？**  
检查是否套了画板比例又选了偏低的分辨率——那是把大图缩小塞进小页面。要用原始清晰度，勾「导出画板原分辨率」。

**画板框自己变大了？**  
「自动画布」开着。它只往外套、不往里收，往画板里添了内容就会长。要精确收回内容边界，点「贴合内容」；不想要这个行为，在右侧「画板」页把它关掉。

**两块画板都开「跟随内容」会叠在一起吗？**  
不会。每块画板只跟**落在自己里面**的图片、标注和形状走，板外的素材不算——两块并排的细节图各框各的。如果某块画板之前被全局内容撑得很大，选中它点一次「贴合内容」，它会收回自己那份。

**导出后发现图被裁掉一截？**  
画板边框没盖住要出的那块。点画板行尾的「定位」跳过去看清楚，拖边框或点「贴合内容」。

**多块画板导出只下载了一个文件？**  
浏览器拦了多文件下载，看地址栏右侧的提示，允许本站下载多个文件后再导一次。

**文字在 Illustrator 里选不中？**  
确认导出的是 SVG 而不是 PDF/PNG。SVG 才是分层矢量。

**换了台电脑打不开旧项目？**  
存档在本机浏览器里，不会跟着账号走。在原机器上「导出项目文件」，把文件拷到新机器：拖进窗口，或用左栏「项目 → 导入项目」在当前窗口打开。

**离线版和在线版有什么区别？**  
没有功能区别——仓库里那份 `cmf-annotator.html` 就是同一套代码构建出来的同一个文件。在线版打开即用、换设备也能打开；离线版放在本地，断网、内网、机器上什么都没装也能跑。两边的**存档互不相通**（浏览器按来源分别存放），要来回搬就用「导出项目文件」。另外离线版走的是 `file://`，个别浏览器会拦掉本地存储——存不进去时工具不会报错，但刷新就回不去了，做完记得导出项目文件。

**同一个方案开了两个窗口，改动被覆盖了？**  
两个窗口指向同一个 `?doc=` 时，谁后保存谁说了算。要并行改，用「增加项目」把方案存成两份，各开一个窗口。

**双击空白没生成形状？**  
先确认工具条上选的是五种形状工具之一，并且双击的位置确实是空白——落在信息栏、已有形状或图片上时不会新建。

直线 / 圆形 / 矩形要**点两下双击**：第一组双击定起点，移动鼠标会看到实线预览，第二组双击才落终点。只双击一次只是把起点定住，还没成形状；不想要了按 `Esc` 或 `Ctrl/⌘ + 左键` 丢掉起点。

**形状在导出图里不见了？**  
检查左栏图层里这一行的眼睛是不是关掉了，或所在分组被隐藏了；隐藏的图层不出图。另外画板边框要盖住形状，否则会被裁掉。

**版本号没有自动加？**  
栏目名必须叫「版本号」或「版本」，改名成其他内容就不再生效。
