三步上手

不用装软件，不用注册。打开网页或本地那个 HTML 文件就能开始。

导入渲染图

点左栏「上传 / 拖入渲染图」，或直接把图片拖进窗口。同一产品的多个角度可以一次选中，会按顺序并排铺开。

拉引线，填 CMF

选「标注」工具，在部件上双击落点、再双击落框。材质和工艺点标签就能填，颜色填潘通色号。一条标注写一个部件。

框画板，导出

在左栏加一块画板框住要交付的区域，选好比例和底色，然后在左下「导出设置」里选 DPI 和格式，导出 PNG / PDF / SVG。

它能做什么

按一张 CMF 交付图需要的环节来组织，不是一堆散装功能。

引线标注

一条标注对应一个部件，引线自动避让，标注框可拖动、可缩放，不用手动对齐。

材质 / 工艺 / 颜色

三栏分开填。常用材质和工艺点标签即可，颜色记录潘通色号，交付时不留歧义。

项目信息栏

产品名、版本、日期、设计师等字段可自行增删。版本号填数字会自动递增。

画板与自动画布

按 1:1、4:3、16:9 或自由比例框出交付区域，底色可透明。勾「跟随内容」后，加图会自动贴合。

多格式导出

PNG / JPEG / WebP / PDF / SVG。96–300 DPI 或原始分辨率，每块画板可以各设各的。

数据留在本地

图片和标注只存在你自己的浏览器里，不上传服务器。也可以下载单文件，断网使用。

几个常被问到的问题

还有更细的操作说明，见工具内「关于」卡片里的完整教程。

要收费吗？要注册吗？

免费，也不需要注册。打开网页就能用；想要离线版，下载一个 HTML 文件，双击用 Chrome 或 Edge 打开即可，功能和在线版一样。

图片会被上传到服务器吗？

不会。所有图片、标注和设置都保存在你自己浏览器的本地存储里，工具没有后端。换电脑或清理浏览器数据后旧存档会看不到，重要项目请用「导出项目文件」备份。

能导出给下游继续编辑吗？

可以选 SVG。渲染图、每条标注、形状、信息栏、水印各自是独立图层，文字是真正的文本，在 Illustrator 里能逐层选中、直接改字。需要 PDF 就在 AI 里另存。

和直接在 PPT / Figma 里圈有什么区别？

圈只是画个圈，材质工艺还得另写。这里每条引线自带材质、颜色、工艺三栏，颜色存的是潘通色号，导出就是一张信息完整的总表，不用再拼第二遍。
